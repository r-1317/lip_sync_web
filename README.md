# LipSync Web

音素ラベル（`.lab`）と立ち絵画像から、音声付きの透過MOVを作成します。[lip_sync_tool](https://github.com/r-1317/lip_sync_tool) のラベル使用時の機能を静的Webアプリにしたものです。

## 動画の形式についての注意点

このツールで生成されるQuickTime Animation形式の動画は、多くの動画編集ソフトで扱えますが、一部のソフトでは対応していません。お使いのツールで読み込めない場合は、他の映像コーデックに変換してお使いください。

また、この形式の動画はWindowsやmacOSの標準プレイヤーでは再生できませんのでご注意ください。

## 起動

リポジトリ直下の `index.html` をChromeで開いてください。ビルド・インストール・サーバーは不要です。すべての処理はブラウザー内で行い、素材を外部へ送信しません。外部CDNやRhubarb、FFmpegにも依存しません。

## 単体処理

1. 2枚・3枚・9枚モードとFPS（1〜120）を選択します。
2. 音声とUTF-8の`.lab`を選択します。WAV、MP3、FLAC、M4Aなど、Chromeがデコードできるモノラル・ステレオ音声に対応します。
3. 同じピクセルサイズの透過PNG / WebPを口形ごとに指定します。入力欄へのドラッグ＆ドロップも使用できます。
4. 必要に応じて「口形の割り当て」を変更します。
5. 音声付きのプレビューとタイムラインで確認し、「透過MOVを書き出す」を押します。

プレビューの背景色は確認用です。MOVには含まれません。元画像のサイズとアルファチャンネルを保持します。音声よりラベルが長い場合はラベル終了まで、ラベルより音声が長い場合は音声終了まで動画を作成します。ラベルの隙間・終了後はXの画像を表示します。

## ラベル形式

UTF-8（BOMも可）、空白またはタブ区切りの3列です。開始・終了時刻は **100 ns単位の整数**で、`10000000` が1秒です。

```text
0 1000000 pau
1000000 5000000 a
5000000 10000000 u
```

VOICEVOXの45種類の音素と互換用の`l/ng/sil/sp`に対応します。元ツールと同じく、`a→D`、`i→B`、`u→F`、`e→C`、`o→E`、`p/b/m→A`、`f/v→G`、`r/ry/l→H`、その他の対応子音→B、`pau/sil/sp/cl→X`です。無声化母音`A/I/U/E/O`も同じ口形になります。不正な行・重複区間・未対応の音素はファイル名と行番号で表示します。

## フォルダー一括処理

1. 立ち絵画像・口形・FPSを設定します。
2. 「フォルダー一括処理」で入力欄をクリックしてフォルダーを選択するか、フォルダーをドロップします。
3. 「一括処理してZIPを作成」を押します。

フォルダー直下の音声と同名の`.lab`を組にして処理します。サブフォルダーは対象外です。例：`voice.wav` + `voice.lab` → `voice.mov`。ラベルのない音声はスキップし、不正な音声・ラベルのあるファイルは失敗を表示して、残りの処理を続けます。出力名が重複する音声は除外します。

完了したMOVをZIPでダウンロードできます。失敗・スキップがある場合は`処理結果.txt`も含めます。キャンセル時は、それまでに完了した動画をZIPにまとめます。ZIP作成中はキャンセルできません。

## プリセット

「画像と設定を保存」で、立ち絵を埋め込んだJSONを保存します。読み込むと画像、モード、FPS、口形の割り当てを復元します。音声・ラベルはその都度選択してください。元のlip_sync_toolの`format_version: 1`のプリセットも設定を読み込めますが、ローカルファイルのパスにはアクセスできないため、画像を選択する必要があります。

## 出力と制限

- 動画：QuickTime Animation（`qtrle`）、32ビットARGB、指定FPS、ロスレス。
- キーフレームは先頭のみです。口形画像の全組み合わせの行単位の差分を事前計算し、切り替え時も変化のない行の画像データは省略します。同じ画像が続くフレームは前の画像を再利用します。
- 音声：48 kHz、16ビットPCM、モノラルまたはステレオ。
- Chromeでの確認はアプリ内のプレビューを使用してください。出力MOVはQuickTime Animation対応の動画編集ソフトで読み込めます。Chromeの動画プレーヤーでは再生できない場合があります。
- メモリー内で処理するため、画像は1600万ピクセル以下・80 MB以下、音声は250 MB以下、MOV・ZIPは各2 GB以下に制限しています。大きな素材は端末の空きメモリーによって処理に失敗する場合があります。
- LinuxおよびWindowsのChromiumで確認済みです。macOSでの動作は確認していません。

## 開発・検証

外部パッケージは不要です。

```sh
node --test tests/core.test.cjs tests/media.test.cjs
```

MOVのテストはキーフレーム数と行差分の記録を検証します。FFmpeg / FFprobeがある場合、外部デコーダーでフレーム数・FPS・音声・アルファ・2・3・9枚モードの全口形ペアの切り替えとシークも検証します。ない場合、このデコード検証のみスキップします。ZIPの外部検証にはPython 3を使用します。

既存のChrome / Chromiumを使うブラウザーテストは次の手順で実行できます。`CHROMIUM_PATH`で実行ファイルを指定できます。

```sh
npm install --prefix /tmp/lipsync-qa playwright-core
PLAYWRIGHT_MODULE=/tmp/lipsync-qa/node_modules/playwright-core node tests/browser.cjs
```

検証済み：`file://`での起動、サブディレクトリでのHTTP配信、2・3・9枚モード、音声再生とシーク、透過MOVの保存、プリセット復元、不正なラベル・画像サイズ・透過のない画像の検出、ZIPの日本語ファイル名、失敗後の処理継続、キャンセルと完了済み動画の保存、フォルダーのドロップ・クリック選択、100件以上のファイルと空フォルダーの読み込み、フォルダー直下のみの処理、スマートフォン幅のレイアウト。`tests/testdata/zundamon`がある場合は、そこにある8組の音声・ラベルも一括処理します。元のテスト素材は変更しません。
